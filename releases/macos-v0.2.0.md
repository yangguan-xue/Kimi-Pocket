# macOS v0.2.0 · 首个状态栏原生发布版

Kimi Pocket 首个 macOS 原生顶栏常驻版本，适用于 **macOS 14 (Sonoma) 及以上（Apple Silicon arm64）**。

## 本版功能

- **极简顶栏常驻**：系统级 22×22 紧凑星芒图标（✨），无 Dock 栏图标打扰，轻巧无感。
- **纯即时悬停（Zero-Click）**：
  - 鼠标悬停超过 180ms 自动平滑展开 Obsidian Dark 暗色毛玻璃浮窗。
  - 光标移出后 250ms 自动平滑收起，或在屏幕任意处点击、按 `ESC` 键即可即时退出。
  - 彻底去除固定/常驻锁定模式，绝不遮挡日常操作与编码。
- **三核心额度看板**：
  - **5小时额度**：平滑单条进度，展示纯净百分比与重置倒计时。
  - **本周用量**：7 段离散几何药丸条，展示纯净百分比与重置周期。
  - **总用量**：4 段离散几何药丸条，直接标注具体的套餐到期时间（`到期时间: YYYY-MM-DD`）。
- **三级色彩动态预警**：
  - `< 80%`：冷翠绿 / 冰蓝
  - `≥ 80%`：琥珀黄预警（进度条、药丸点亮段联动变黄）
  - `≥ 90%`：珊瑚红告急
- **系统硬件安全与剪贴板**：
  - Token 安全存入 macOS 硬件级 Keychain（钥匙串）。
  - 偏好设置支持键盘 `⌘V` 粘贴与一键【📋 粘贴】按钮。

## 下载与安装

提供两种便携分发格式，任选其一：

1. **DMG 安装镜像（推荐）**：
   - 下载附件 **`Kimi-Pocket-macos-arm64-0.2.0.dmg`**；
   - 双击挂载后，直接将 `Kimi Pocket.app` 拖入 `/Applications`（应用程序）文件夹即可运行。
2. **ZIP 便携归档**：
   - 下载附件 **`Kimi-Pocket-macos-arm64-0.2.0.zip`**；
   - 解压后双击运行即可，保持所有系统权限完整。

> [!TIP]
> 首次运行如果遇到 macOS Gatekeeper 提示“无法验证开发者”，可以在系统的「系统设置 -> 隐私与安全性」底部点击「仍要打开」，或在终端执行：
> ```bash
> xattr -cr /Applications/Kimi\ Pocket.app
> ```
