# SPEC-03: 移动端自适应与双形态 UI/UX 规范 (Responsive UI Spec)

- **文档编号**：`SPEC-03`
- **对应阶段**：`Phase 3: 响应式组件与视觉体系`
- **状态**：`APPROVED` (已评审)

## 1. 设计语言与调色板

- **设计美学**：Obsidian Dark、务实、高级、简约、工业级仪表盘质感。
- **调色板定义**：
  - 背景色：`#0B0C10`（极深曜石黑，降低 OLED 屏功耗）
  - 卡片底色：`#12141A`（磨砂暗黑微透明，配 1px `rgba(255, 255, 255, 0.08)` 细边框）
  - 正常用量高亮光晕：`#00E5FF`（冰蓝 / Cyan）与 `#10B981`（冷翠绿 / Emerald）
  - 预警告急：`#F59E0B`（黄色预警）、`#EF4444`（红色预警）
  - 等宽字体：`ui-monospace, "SF Mono", "JetBrains Mono", Roboto Mono, monospace`

## 2. 竖屏模式 (Portrait Mode) 规范

适用于手机手持竖向浏览，布局为 3 张垂直自适应卡片：

### 2.1 卡片 1：总用量 (Total Quota)
- **形态**：**4 个水平离散药丸段**（`grid grid-cols-4 gap-2`）。
- **填充逻辑**：
  - 每个段代表 25% 额度；
  - 段 1 (0%~25%)、段 2 (25%~50%)、段 3 (50%~75%)、段 4 (75%~100%)；
  - 当前落入的段支持部分渐变填充或整段点亮。
- **标注信息**：`已用 X / 总额 Y`、`使用率 Z%`。

### 2.2 卡片 2：周用量 (Weekly Quota)
- **形态**：**7 个水平离散药丸段**（`grid grid-cols-7 gap-1.5`，象征一周 7 天）。
- **填充逻辑**：
  - 每个段代表 `100% / 7 ≈ 14.28%` 额度；
  - 直观映射本周内 7 天的消耗节奏。
- **标注信息**：`已用 X / 总额 Y`、右下角高亮标签 `X天后重置`。

### 2.3 卡片 3：5小时额度 (5-Hour Rolling)
- **形态**：**单条完整平滑水平进度条**（`rounded-full`，不分段）。
- **填充逻辑**：平滑宽度百分比（0% ~ 100%），带轻微呼吸光晕。
- **标注信息**：`已用 X / 总额 Y (剩余 Z)`、右下角高亮标签 `X小时Y分后重置`。

## 3. 横屏模式 (Landscape StandBy HUD) 规范

适用于横置手机放支架/桌面待机充电，布局为**三圆环仪表盘（左-中-右并排）**：

### 3.1 渲染数学公式与 SVG 规范（圆半径 $R = 45$，周长 $C = 2\pi R \approx 282.74$）

| 仪表环 | 分段规则 | SVG `stroke-dasharray` 计算公式 | 环心信息 | 环底标注 |
|---|---|---|---|---|
| **左环 · 总用量** | **严格 4 段圆弧** | 每段弧长 $L_4 = (282.74 - 4 \times G) / 4$<br>设间隙 $G=8$，则每段约 $62.6\text{px}$ | 大字 `65%`<br>小字 `65 / 100` | 总用量 (4段) |
| **中环 · 周用量** | **严格 7 段圆弧** | 每段弧长 $L_7 = (282.74 - 7 \times G) / 7$<br>设间隙 $G=6$，则每段约 $34.3\text{px}$ | 大字 `42%`<br>小字 `42 / 100` | 周用量 • 3天后重置 (7段) |
| **右环 · 5小时** | **单环连续平滑弧** | 完整圆周，已用填充弧长 $= 282.74 \times \text{ratio}$ | 大字 `30%`<br>小字 `余 42 / 60` | 5小时 • 1h42m 后重置 |

### 3.2 模式切换触发机制
- 采用 CSS 媒体查询：`@media (orientation: landscape)` 与 `window.matchMedia` 双重监听。
- 自动隐藏非核心折叠项，全屏沉浸，居中等比缩放。
