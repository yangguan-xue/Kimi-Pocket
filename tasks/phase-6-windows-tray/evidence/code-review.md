# Windows 实现复核

日期：2026-11-04。复核范围为 windows/ 新工程与构建脚本；本记录用于 `windows-v0.1.0` 预览发布，未将全部实机验收标记为完成。

## 已修复并复验

- WPF Run.Text 对只读 ViewModel 属性的默认双向绑定导致预览无法显示：明确 OneWay，并以 10 种状态的真实 STA WPF 布局测试与打包 EXE 捕获回归。
- 403 后不应持续后台重试：停止后台触发，保留显式手动重试；401/过期仍清除凭据相关内存快照并停止请求。
- 暂停/更换凭据时的在途请求：取消与代次检查阻止晚到结果覆盖；恢复后允许新一轮刷新。
- 非法 JSON 根节点及网络读异常：按不可识别数据/网络错误分类，独立分区结果保留各自更新时间。
- 菜单、设置和锁屏的抑制生命周期发生重叠时，单一布尔状态会提前释放：改用独立原因集合，禁止抑制中的点击/键盘重开；菜单关闭不干扰仍打开的设置焦点。新增 7 项测试覆盖重叠释放、重复通知及各入口。先以 3 个失败用例复现，再修复通过。
- 按钮、复选框和文字选区使用灰阶样式；文字缩放缓存原始字号，避免重复应用后继续增大。

## 已检查的边界

Core 无 WPF 依赖；请求有响应大小与整体超时限制；禁止自动重定向；不输出 Token/原始响应；凭据无明文持久化回退。原生托盘、图标、窗口 Hook、计时器、HTTP 与单实例资源有退出释放路径。设计预览与真实凭据/启动项隔离。

构建脚本检查非零用例和失败结果，避免零测试假通过；格式检查、Release 编译、测试和发布均以非零退出阻断失败。自包含目录发布关闭 trimming；实际 ZIP 已作解压启动和运行时来源检查。

## 仍需实测的风险

Shell 溢出区消息时序、菜单焦点及真实指针跨区、混合 DPI 与热插拔、Narrator/高对比度、系统恢复及真实账号交互尚未经过完整实机验收。清单与结论统一见 acceptance.md；这些项阻止将首版标为全部 VERIFIED。
