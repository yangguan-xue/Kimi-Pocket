# Release 性能和资源记录

测量日期：2026-11-04。Windows 11 Pro 10.0.26200；Intel Core i5-12490F，12 个逻辑处理器。使用 Release 程序和本地 .NET 10.0.14，`--design-preview --tray`，面板隐藏、固定数据、无网络请求。

| 项目 | 观察值 | 口径与结论 |
| --- | --- | --- |
| 稳定运行 | 316.546 秒 | 超过 5 分钟；只覆盖隐藏预览托盘 |
| CPU | 140.004 秒内计时无增长，计算平均 0.0% | Δ进程 CPU 秒 / Δ墙钟秒 / 12 ×100；受系统计时粒度限制，不宣称绝对零 CPU |
| Private Bytes | 45.957 MiB | 本样本低于 100 MiB 目标 |
| Working Set | 88.789 MiB | 与 Private Bytes 分别报告 |
| Handles | 590 → 586 | CPU 采样区间前后；单次样本无增长 |
| 100 次原生开合 GDI | 17 → 17 | 独立 Windows 集成测试，真实 Shell 图标及 WPF HWND |
| 100 次原生开合 USER | 31 → 25 | 同上；每次前台 HWND 保持不变 |
| 首次托盘可操作 ≤2 秒 | 未测 | 成功启动不能推导出耗时通过 |
| 180 ms 防抖后绘制 ≤100 ms | 未测 | 状态机时序测试只验证逻辑边界 |

进程 CPU/资源原始记录位于本地 `dist-windows/performance.json`、`perf-baseline.json` 与 `perf-process.json`；原生资源结果取自最终构建 TRX，摘要同时保存于 build-results.json。

该资源采样使用最终打包前、同日的 Release 预览版本，早于最后的辅助功能样式整理。真实联网、设置窗口、不同系统缩放与休眠恢复可能影响资源；本次数据只作为初步基线，不是全部性能目标的验收结论。需在最终包、真实账号、同一采样口径下完成后续实测。
